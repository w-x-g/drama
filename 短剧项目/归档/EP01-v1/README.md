## 为什么保留

- 第 01 课「景别与信息释放」、第 02 课「视觉命题与风格锚点」的教学示例仍以这版为素材；
- 26 镜版在景别分布和跳级设计上更细，适合对照学习；
- 不再作为 EP001 的制作基线，避免与 H3 18 镜版混淆。
