## 基本数字

- 镜数：20 镜（SHOT-EP004-001 至 SHOT-EP004-020）
- 总时长：90 秒（每镜 4–15 秒整数；无半秒镜）
- 平均镜长：4.5 秒
- 近景类：15 镜，占 75%（满足 `close_shot_share_min` 0.45）
- 对白：182 个可发声汉字；15 个对白镜，每镜开口前留 0.5 秒
- 语速：按 4.1 字/秒约 44.4 秒发声；按 4.5 字/秒约 40.4 秒；加上开口延迟共约 47.9–51.9 秒，余下为动作、反应与静默
- 最快一句：SHOT-EP004-006，18 字 / 4.5 秒窗口 = 4.00 字/秒；其次是 SHOT-EP004-009，33 字 / 8.5 秒窗口 = 3.88 字/秒
- 目标模型：MiniMax H3；20 镜全部 full-reference（起始帧 + 身份/地理/道具板），正文为六段一条提示词
- 未调用任何付费 API

## 色彩弧线如何落实

资产圣经 EP004 的总色是「暖烛 + 梅红」，本集按总纲允许的集内对比拆成四段，不把开场冷白删掉：

1. **SC001 江家庭院（001–007）**：冷白晨光、梨花白、青石冷灰，光比 1:7。耳光之后只让东墙墙头出现一线暖边，不铺满院子；到 007 的南院门，门框外第一次出现暖白光，光比回到约 1:5。
2. **SC002 江家门外青石路（008–011）**：暖白日光从东侧来，光比 1:4。裴珩的玄色吸光，她的月白被晒暖；梨花瓣落在青石上。这是由冷转暖的过渡点。
3. **SC003 沈家院门（012）**：暖白晨光加门灯橙，光比 1:4。退婚书烧完的灰是全片最后一次冷灰，但周围的光已经暖。
4. **SC004 沈府门前长街（013–014）**：暖日，红漆礼箱是画面最大面积的红，光比 1:3；白墙被晒暖，黛瓦仍冷。红从这一镜正式接管全集。
5. **SC005 新居洞房（015–020）**：暖烛加梅红，光比 1:2.5，全剧最暖。窗外只透一条冷蓝窗纸边，作对比，不作主光；金线只偶尔反光，不做满身亮片。

## 不确定的地方

1. **SHOT-009 语速最紧**：33 字 / 7.5 秒 = 4.40 字/秒，低于任务上限 4.5，但高于项目配置的 4.1。若按 4.1 字/秒执行，建议这一镜加到 9 秒，或把「远远」二字删去（30 字 / 7.5 秒 = 4.0 字/秒）。目前按任务给的 4.5 上限保留原文。
2. **梅枝是新增项**：资产圣经第 9.3 条注明「梅枝/种梅」为新增，需创作者确认。若创作者不确认，只保留 015 的绣梅帕与「拔梨树」台词，洞房不插梅；LOCK-PLUM-BRANCH 随之从本集移除。
3. **烧退婚书的地点**：为不新建沈府室内，烧纸放在 EP002 已有的「沈家院门」，用门灯代替室内烛台。若创作者要求严格按原著「搁到烛台旁」，需要补一个沈府内室场景板，本集没有建。
4. **江家管家**：按群演处理，只拍深色袖口与双手递纸，不建资产、不给正脸。
5. **长街红箱与烧纸不同场**：LOCK-STREET 的锁面包含红漆礼箱，所以 012 烧纸不用长街板，改用沈家院门；013 才用长街板。这样锁面不会在「还没有聘礼」的镜次里说谎。
6. **裴珩「暗恋八年，等你三年」的年龄算术**：沿用资产圣经第 9.8 条，不改台词，只做「二十出头」的年龄感。
7. **所有挂图都是 PLAN**：本集没有真实图片进项目，20 镜的 `PLAN-...` 由创作者在 H3 界面按「顺序」挂载；`<Picture N>` 与顺序一一对应。要投产，先把图放进项目改成 `REF-...`。
8. **H3 模式**：每镜同时有起始帧和身份/地理/道具板，按 H3 方言全部走 full-reference 六段，不拆成 first_frame 加 reference。若创作者只想挂起始帧，需回分镜阶段把其余槽位删掉，不能在本阶段偷改。
