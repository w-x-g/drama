# 造型变体生成流程与 EP001 成品

> 依据 `项目开发/投产顺序.md` 第二节。造型板只改服装与状态，**不改脸**；脸一律来自 `资产/人物身份板/` 的成品图。

## 一、最终工作流：Qwen-Image-Edit 2511 指令编辑

试过三条路线，只有这条同时守住了「脸不变」和「服装形制可控」。

| 路线 | 结果 | 结论 |
|---|---|---|
| Z-Image 参考图通道（`TextEncodeZImageOmni` + `clip_vision_h`） | 报错：CLIP 视觉网格与潜在网格尺寸不匹配 | 不可用 |
| Qwen-Image 2.1 编辑（`TextEncodeQwenImage21` + `qwen_image_2.1_turbo`） | 脸部糊成一团 | 不可用（2.1 turbo 是文生图，不是编辑模型） |
| Z-Image img2img（denoise 0.6–0.8） | 0.6 只改局部、0.8 领型变成立领盘扣，头发也被改 | 不可靠 |
| Z-Image 同 seed txt2img（只换服装句） | 形制对，但脸会漂，且质感只能靠提示词碰 | 备选 |
| Z-Image 遮罩局部重绘 | 脸像素级不变，但蒙版下沿有接缝、手被画坏 | 备选 |
| **Qwen-Image-Edit 2511 指令编辑** | **脸不变、形制正确、质感可控** | **采用** |

### 1.1 模型与参数

| 项 | 值 |
|---|---|
| 扩散模型 | `qwen_image_edit_2511_int8_convrot.safetensors`（20.5 GB） |
| 文本编码器 | `qwen_2.5_vl_7b_fp8_scaled.safetensors`（9.4 GB） |
| VAE | `qwen_image_vae.safetensors` |
| 加速 LoRA | `Qwen-Image-Edit-2511-Lightning-4steps-V1.0-bf16.safetensors`，强度 1.0 |
| 采样 | 4 步，CFG 1.0，`euler` + `simple`，denoise 1.0 |
| 负向 | `ConditioningZeroOut` |
| 参考图处理 | `LoadImage` → `FluxKontextImageScale`（编辑图尺寸必须由参考图决定，不能用空 latent） |

节点链：

```
UNETLoader → LoraLoaderModelOnly ─┐
CLIPLoader ────────────────────────┤
VAELoader ─────────────────────────┤
LoadImage → FluxKontextImageScale ─┼→ TextEncodeQwenImageEditPlus → KSampler
                    │              │                                    ↓
                    └→ VAEEncode ──┴────────────────────────────→ VAEDecode → SaveImage
```

**关键点**：`latent_image` 必须来自参考图的 `VAEEncode`，不能用 `EmptyLatentImage`，否则会重新合成而不是编辑。

### 1.2 提示词范式

固定四段，按顺序写：

1. **保什么**：`Keep her face, her features, her age, her hairstyle and the three poses exactly the same.`
2. **改什么**：`Change only her clothing: ...`（写清形制、颜色、缘边、腰饰）
3. **质感**：丝 / 棉分开写，见下节
4. **禁止项 + 保留项**：`Do not add any stand-up collar, mandarin collar, buttons or frog closures. Keep the neutral light grey background and the bright even lighting unchanged.`

### 1.3 材质口径

- **丝（主仆有别：主角用）**：`fine silk with a soft, muted, almost matte lustre — a gentle sheen only where the cloth turns over at the folds, not glossy satin, no plastic shine, no hard specular highlight, natural soft creases, heavy fluid drape, visible fine weave`
  - 教训：只写 `lustrous silk` 会出缎面化纤感，古装味道全没；必须同时写「哑光、只在褶子转折处有光」。
- **棉（丫鬟、粗使）**：`cotton with a fine visible weave and a matte surface, gently worn, natural soft creases`。
- 一律加 `no stand-up collar, no mandarin collar, no buttons`——Qwen 编辑容易把交领改成立领盘扣（清装）。

## 三、已知偏差

| 项 | 情况 |
|---|---|
| 临终中衣的年龄感 | 闭眼躺卧，不容易读出「二十三岁的憔悴」；颧骨与唇色的老成度偏轻 |
| 江砚白的气质 | 编辑后比身份板柔和一点，笑意略多 |
| 春杏体型 | 比身份板瘦了一些，「敦实」的横向量减弱 |
| 分辨率 | 编辑输出由 `FluxKontextImageScale` 决定，约为 1248×832，与身份板的 1536×1024 不完全一致 |

以上都记在案，若后续关键帧需要更贴，可回到身份板重跑同一提示词并换 seed。

## 四、复用规则

1. 每一集的造型变体都**以身份板为参考图**，不以上一集的造型板为参考，避免逐代漂移。
2. 同一角色的不同造型之间不互为参考。
3. 出完造型板后，用 `lihuawu-qc` 的视觉评审清单逐项过：同一张脸、锁面逐字、光线方向、道具状态。
