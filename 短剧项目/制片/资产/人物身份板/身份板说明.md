## 一、生成规格

| 项 | 值 |
|---|---|
| 引擎 | ComfyUI 0.42.0（本地） |
| 模型 | `z_image_turbo_bf16.safetensors`（Z-Image Turbo 6B） |
| 文本编码 | `qwen_3_4b.safetensors`（CLIPLoader type=`qwen_image`） |
| VAE | `ae.safetensors` |
| 采样 | KSampler，10 步，CFG 1.0，`dpmpp_sde` + `beta`，denoise 1.0 |
| 负向 | `ConditioningZeroOut`（Turbo 蒸馏，负向无效） |
| 尺寸 | 1536 × 1024（横版三栏） |
| 版面 | 左中右三栏：正面 / 四分之三侧面 / 正侧面 |
| 底色 | 中性灰背景，均匀柔光自左前方 |
| 服装 | 一律素白无纹交领内袍——**身份板不绑定任何一集的造型** |
| 极简节点图 | UNETLoader → CLIPLoader → TextEncodeZImageOmni → KSampler → VAEDecode → SaveImage |

## 四、使用规则

1. **只挂成品图，不改脸描述**。造型变体（EP002 出行披风、EP003 病中寝衣、EP004 婚服等）一律以本目录对应身份板为参考图，提示词只改服装与状态。
2. **跨集共用**。EP001–EP004 的同一角色是同一张脸，不允许每集重新生成。
3. **沈岁宁 16/23 岁**是同一 Character 的两个年龄状态：用 `IMG-ID-SHEN.png` 作参考，靠年龄描述（颧骨显、眼窝微陷、唇色灰白）做状态变体，不建第二个身份。
4. 主持、沈府门房不在本次六张之列；两人均为单镜/次要角色，需要时可按本文件第三节的方法补出。
