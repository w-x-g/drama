# 故事引擎 · 梨花误

## 1. 已接受的戏剧承诺

沈岁宁带着临终那晚听到的三句话回到婚约当日。她要做的不是报复，是**退出**：把这段即将成立的婚姻从自己身上摘下来，并且让所有人以为这是他们自己的决定。观众每一轮获得的回报，是她用最少的动作挪动对方的判断——一句话、一次沉默、一个不接。

## 2. 引擎回路

### 压力怎样启动

每一轮压力都从**日程**开始：换帖日、婚期、温蘅的病、长辈的寿宴、佛寺的法事。日程不等人，所以她必须在日程之前行动，而不能只躲。

### 主角惯常怎样应对

她不吵、不哭、不解释。她的惯用动作只有三种：

1. **打断**——在对方把话说完之前把结论拿走（"婚约的事，我想再缓一缓"）；
2. **转交**——把一件她不想做的事交给一个对方无法拒绝的人（备笔墨、送信）；
3. **误认**——让对方按旧印象理解她的新动作（他以为她身子不舒服，其实她已经不要他了）。

### 对抗力量怎样学习与反制

江砚白不会学。他的反制方式恰恰是**加倍温柔**：她越冷，他越体贴；他每体贴一次，就把她重新放回"从前的沈岁宁"的位置上一次。真正的学习发生在温蘅身上——温蘅很快会意识到，这个女人不是在闹脾气，而是在撤出。

### 一轮冲突怎样留下下一轮压力

```text
日程逼近 → 她用"退一步"争取时间 → 他按旧印象解读为顺从
→ 他的"温柔"暴露了他真正在意的人 → 她获得新的信息与新的行动空间
→ 她把空间立刻用掉（写信给别人） → 新的事实开始自己走动
```

关键在于：她的每一步都不制造敌人，只制造**时间的复利**。她越安静，他越松懈；他越松懈，她越能在他背后把线接出去。

### 为什么人物不能轻易退出

- **沈岁宁**：退婚不是她一个人的事，是沈家的面子。她若强退，先被家族按住。
- **江砚白**：他不能承认自己选错了，否则他一生的"无愧于心"就成了谎言。
- **温蘅**：她的位置从来不是正妻，她需要沈岁宁先让出这个位置。
- **裴珩**：他能退，所以他一直在退；这正是他的问题。

## 3. 可升级的状态

| 状态 | 起点 | 可升级方向 |
|---|---|---|
| 婚约 | 今日换帖 | 换帖 → 延后 → 长辈施压 → 作废 |
| 知情范围 | 只有她知道前世 | 裴珩知道一部分 → 温蘅察觉 → 江砚白最后知道 |
| 她的名声 | 温顺守礼 | 身体不适 → 不识大体 → 主动退婚 |
| 裴珩的位置 | 街对面的陌生人 | 收信人 → 同盟 → 选择 |
| 梨花的含义 | 他的顺手 | 她的道具 → 那首诗的题目 → 她自己的名字 |

## 3b. 前提装置契约

装置：**重生**（带着前世记忆回到十六岁）。

- 边界：她只能记得自己亲历或亲见的事；她死后魂魄所见（灵前、玉扣）是模糊的、片段的，不能当全知使用。
- 代价：她知道结果，但不知道过程；她能避开一次伤害，却改变不了别人为什么那样做。
- 不能做的事：不能预知她没见过的事（例如温蘅后来的病情走向）；不能靠记忆获得她前世没有的资源。
- 观众知情：观众与她同步，只知道她知道的。

## 4. 人物行动模型

### 沈岁宁 / CHAR-SUINING

- 目标：退出婚约，且不承担"毁约"的骂名。
- 被捍卫的信念：人可以看出来，只要你不肯看。
- 惯常策略：打断、转交、误认。
- 盲区：她把所有人都当成可计算的，包括裴珩——而她对他几乎一无所知。
- 筹码：沈家女儿的身份、未换帖的空档、春杏。
- 底线：不害人；但会利用别人的感情。
- 改变她的东西：裴珩真的来了。

### 江砚白 / CHAR-YANBAI

- 目标：两全——婚约照旧，温蘅也照顾到。
- 被捍卫的信念：我没有亏待过谁，我只是没得选。
- 惯常策略：温柔、拖延、把选择说成被迫。
- 盲区：他从不认为自己在做选择，所以从不设防。
- 筹码：礼法、两家的面子。
- 改变他的东西：她真的不要他了——那会让他第一次必须承认自己选过。

### 春杏 / CHAR-CHUNXING

- 目标：护着姑娘，又不惹事。
- 策略：先说一半，看反应再说另一半。
- 作用：唯一能自由进出佛寺与侯府的人——信息与行动的通道。

## 5. 关系压力网

### 沈岁宁 ↔ 江砚白

- 她需要他 / 害怕他看见 / 用来约束他的东西：需要婚约作掩护；害怕他看出她换了个人；用"身子不爽利"约束他的追问。
- 他需要她 / 害怕她拿走 / 用来反制她的东西：需要她的顺从维持体面；害怕她当众提出异议；用"等我回来再谈"拖延。
- 当前不平衡：他以为自己在掌控日程。
- 可能的变化：从"她等他"变成"他追着问她怎么了"。

### 沈岁宁 ↔ 裴珩

- 她需要他 / 害怕他看见 / 用来约束他的东西：需要一个新的去处；害怕他发现她只是在利用他；用"梨花"这个只有他们懂的词约束距离。
- 他需要她 / 害怕她拿走 / 用来反制她的东西：需要她活着；害怕她再一次不属于他；用沉默反制她的一切试探。
- 当前不平衡：她掌握全部信息，他一无所知。
- 可能的变化：当他发现她知道的比他多，权力会翻过来。

### 江砚白 ↔ 温蘅

- 他需要她 / 害怕她拿走：需要她证明自己"有得选"；害怕她真的离开，那样他的牺牲就没有观众。
- 她需要他 / 害怕他拿走：需要他的名分；害怕他最终还是回到沈岁宁身边。
- 当前不平衡：她病了，他有了一个可以公开奔赴的理由。
- 可能的变化：病好了之后，理由消失。

### 跨集记忆最小集

下一集开场必须记得的四件事：婚约是否已换帖；谁知道她写了信；梨花枝在哪；江砚白人在哪里。

## 7. 主题进入选择

主题不是"爱要不要争取"，而是**"无愧于心"能不能替代在场**。所以每一次选择都必须让两件事对撞：

- 他说的话是对的（他确实没得选）；
- 他没做的事是错的（他确实没来）。

她不反驳他的话，只让他看见自己没做的事。

## 8. 视觉、声音与制作方向

- 色彩弧线：EP001 冷灰 → EP002 冷青 + 佛寺金 → EP003 冷白 + 玉青 → EP004 暖烛 + 梅红。
- 构图：框中框——门框、镜框、窗框、帐幔，人在框里，窥视感来自观众的位置，不来自运镜。
- 声音：无配乐；底声是风、窗纸、烛芯、门轴。马蹄是唯一允许"大声"的声音，因此它一出现就是压力。
- 道具：梨花（顺手 → 蔫 → 落尽）、铜镜（她看自己）、纸与笔（她开始行动）。

## 9. 引擎终止与变形

当江砚白必须在公开场合为温蘅牺牲她时，旧的"温柔拖延"回路失效——他再也无法同时维持两全。那一刻引擎变形为"她与裴珩如何在不被祝福的情况下成立"，而不是结束。

## 10. 分集交接原则

- 每集结尾停在一个**已经开始、无法收回**的动作上（信已送出、人已进门、话已说出口）。
- 下一集开场先接住这个动作的**第一后果**，不重放上一集结尾。
- 交接写成事实（谁在哪里、手里有什么、谁知道什么），不写"局势更紧张"。
