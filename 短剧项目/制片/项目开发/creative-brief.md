# 短剧创作简报 · 梨花误

## 1. 项目意图

- **暂定名**：梨花误
- **一句原始想法**：她用一生等一个说"但求无愧于心"的男人，重生回婚约当日，才发现真正等了她十年的是另一个从不说话的人。
- **这次要完成的工作**：改编开发 + 分集规划 + EP001 的剧本、视觉设定、分镜、图片提示词、视频提示词。
- **来源材料**：`输入/原著-第1-3章.txt`（原著第 1–3 章，只读；第 4–12 章不在本次输入内）。
- **不可更改的来源事实**：
  - 前世临终，江砚白在她床前说"砚白此生，但求无愧于心""我心里，一直只有温蘅" → 落在 EP001，观众看到的是：她闭眼的脸与他画外的声音，随后手松开。
  - 她在婚约宣告之日重生回十六岁，铜镜前眼眶还红着 → 落在 EP001，观众看到的是：镜中睁眼，眼神由茫然转清明。
  - 她当面向江砚白提出"婚约的事，我想再缓一缓" → 落在 EP001，观众看到的是：她打断他，说完收回视线看镜。
  - 江砚白因温蘅病倒离席，留下"等我回来再谈婚事" → 落在 EP001，观众看到的是：门口停住、不回头、门合上。
  - 温蘅在佛寺有他立的长明灯，愿词"百病消散，岁岁平安" → 落在 EP001，观众看到的是：春杏低声回报，她慢慢笑。
  - 她给裴珩写信，署名"梨花" → 落在 EP001（信件内容以画外音出现、名讳后期叠加）；"梨花"这一署名典故延后到 EP002。
  - 裴珩曾攥着一枚玉扣站在她灵前十年，玉扣随棺下葬 → 延后到 EP002；EP001 不交代，只留"她为何写信给他"的悬念。
- **允许改编/探索的范围**：章节边界不按 1:1 切；合并同功能场景（梳妆、换帖、离席、写名、回报名帖、写信合为三场）；压缩对白、删去不改变状态的复述；分集节奏按爽点分布。
- **原著没有、本轮新增的内容**：暂无新增人物或新编的场景。EP001 的"春杏捧笔墨回来顺势回报名帖"是原著两段动作的合并（compress），不是新增事件。

## 2. 创作者契约

- **希望观众反复获得的体验**：看穿之后的冷静反制——她不再解释、不再哭，只用一句轻描淡写把对方的体面拆掉。
- **不希望作品变成什么**：不变成哭诉复仇剧；不把江砚白写成纯粹的恶人；不用旁白替观众总结情绪。
- **主题张力**：体面的自我辩解（"无愧于心"）与真正的在场（十年不说一句话的等待），哪一个才算爱。
- **语气与尺度**：克制、冷、慢半拍；暴力只以关系形式出现，无血腥。
- **结局承诺或禁区**：终局她主动选择裴珩；不写原谅江砚白的复合结局。
- **内容边界**：无露骨情色；无过度血腥；宅斗冲突限于礼法、名分、香火与婚约。

## 3. 形式与制作边界

- **主要语言**：中文（简体）
- **画幅/观看场景**：竖屏 9:16，手机单手观看
- **单集与系列形式**：4 集，单集 60–90 秒；EP001 按 88 秒规划（首集承担重生与动机建立，允许接近上限）
- **可用角色与场景规模**：核心人物 3–5 人；EP001 只有 3 个在场人物、1 个地点；不设群戏
- **难以承受的制作元素**：大规模群众、马匹入画、寺庙实景、复杂打斗、可读中文长文
- **必须保留的视觉/声音特征**：低饱和青灰 + 梨花白 + 烛火橙；框中框窥视构图；梨花作为贯穿物
- **项目节奏档案（候选）**：

```json
{"status": "proposed", "form": "ai_live_action", "first_hook_seconds": 5, "beat_interval_seconds_max": 30, "opposed_reversals_per_episode_min": 1, "end_on_peak": true, "reprise_previous_last_beat": true, "vo_share_max": 0.3, "target_avg_shot_seconds": 5.0, "close_shot_share_min": 0.45, "first_major_payoff_by_episode": 1}
```

`target_avg_shot_seconds` 由 ai_live_action 默认的 2.5 改为 5.0，理由是目标模型 MiniMax H3 单次生成最短 4 秒，平均 2.5 秒的节奏会让绝大多数镜头只能靠多镜容器实现；本集选择"一镜一生成、镜头更长"，代价是镜数从约 30 降到 18。

## 4. 戏剧承诺（工作版）

- **焦点人物**：沈岁宁（重生者，知道所有人的底牌）。
- **当前追求**：把这段婚约从"今日换帖"往后拖，并给自己找一条不靠江家的路。
- **昂贵阻力**：江砚白的体面与温蘅的优先级。他不逼迫、不发怒，只用温柔把她的异议化解为"你身子不舒服"；她若坚持，就要承担"不识大体"的名声。
- **独特矛盾**：她越冷静、越不哭闹，江砚白越确认"她还是从前的沈岁宁"；她的新策略本身在给他错误信号。
- **反复回报**：每一集观众都能看到她用一句轻话、一个动作，把对方自以为稳固的位置挪动一寸。
- **终止性转变**：当江砚白不得不在公开场合为温蘅牺牲她时，旧引擎结束。

**一句工作陈述**：沈岁宁带着上一世的死因回到婚约当日，用"缓一缓"拖住换帖，借江砚白对温蘅的优先把她自己从这段关系里摘出去，并把下一步押在一个从没和她说过三句话的人身上。

## 5. 方向候选与选择

### 候选 A：先知式反制（选定）

- 主角惯常策略：提前知道对方会说什么，用最少的动作改结果
- 主要对抗机制：礼法与日程（换帖、名分、香火）
- 退出成本：退婚会让沈家失面子
- 反复回报：识破 + 一句话反制
- 核心代价：她必须一直扮演"还是从前那个她"
- 引擎终止条件：她的伪装在公开场合被拆穿
- 主要制作负担：室内对话戏为主，成本低
- 擅长提供：信息差快感
- 会牺牲：大场面

### 候选 B：纯宅斗合纵

- 主角策略：联合温蘅的对手反制
- 对抗机制：多方势力
- 退出成本：无
- 反复回报：权力位移
- 核心代价：主角变成算计者
- 引擎终止条件：一方彻底失势
- 主要制作负担：人物多、场景多
- 擅长提供：权谋
- 会牺牲：重生设定的独特性

### 候选 C：先婚后爱的破镜重圆

- 主角策略：接受婚约、在婚姻内部改造江砚白
- 对抗机制：温蘅的回归
- 退出成本：低
- 反复回报：关系温度变化
- 核心代价：取消"退婚"这一核心承诺
- 引擎终止条件：江砚白真正转向
- 主要制作负担：中
- 擅长提供：情感糖点
- 会牺牲：原著"退了婚约"的主线

### 创作者选择

- **选定/组合**：候选 A。
- **选择理由**：与原著"重生 + 退婚 + 另择"的主线一致，且单集成本最低。
- **明确拒绝的方向**：C（会取消退婚主线）；B（人物规模超出 4 集 60–90 秒容量）。
- **仍待确认的分支**：EP002 起裴珩的出场方式（猎场相遇 / 先见玉扣），需与原著第 4–7 章核对。

## 6. 核心人物与关系压力

### 沈岁宁

- 当前目标/意识到的追求：拖住换帖，另找靠山。
- 保护对象/不可失去之物：自己的判断力——她不能再被骗一次。
- 被捍卫的信念："人心是可以看出来的，只要你不肯看。"
- 形成该信念的前史成因：临死那晚他坐在床边说的三句话。
- 惯常策略与优势：不动声色、以退为进、用对方的话反推对方的优先级。
- 策略盲区与代价：她算准了江砚白，却完全不了解裴珩；她对裴珩的判断全部来自死后所见。
- 可用筹码：沈家的女儿身份、婚约未换帖的空档、春杏。
- 底线与可能越线条件：不伤人、不害命；但会利用别人的感情做杠杆。
- 可能改变其策略的事实：裴珩真的回应。

### 江砚白

- 当前目标/意识到的追求：两全——婚约照旧，温蘅也照顾到。
- 保护对象/不可失去之物：自己在所有人眼里的"好人"形象。
- 被捍卫的信念："我没有亏待过谁，我只是没得选。"
- 惯常策略与优势：温柔、体贴、把选择说成被迫。
- 策略盲区与代价：他从不认为自己在做选择，所以从不设防。
- 可用筹码：婚约的礼法、沈家的面子。
- 可能改变其策略的事实：沈岁宁真的不要他了。

### 春杏

- 当前目标：护着姑娘，又不惹事。
- 惯常策略：先咬嘴唇再说话；知道的事说一半。
- 可用筹码：她是唯一能自由进出佛寺与侯府的人。

### 核心关系：沈岁宁 ↔ 江砚白

- 她需要他 / 害怕他看见 / 用来约束他的东西：需要这段婚约作为掩护；害怕他看出她已经不是从前那个人；用"身子不爽利"约束他的追问。
- 他需要她 / 害怕她拿走 / 用来反制她的东西：需要她的顺从维持体面；害怕她当众提出异议；用"等我回来再谈"拖延。
- 当前不平衡：他以为自己在掌控日程，实际上日程已经被她改写。
- 可能发生的关系状态变化：从"她等他"变成"他追着问她怎么了"。

## 7. 叙事切入窗口与前史储备

- **故事切入前已经运行的压力**：江砚白与温蘅的旧情已经存在十年，沈岁宁直到死前才被告知。
- **叙事切入窗口**：她死的那一夜——必须在她听完那句话的瞬间切入，观众和她同时获得"真相"。
- **第 1 集入口候选**：
  1. **时序入口**：铜镜前梳妆，丫鬟绾发，她睁眼。第一格是镜中红眼的十六岁脸，问题："她为什么哭？"整集收益：重生确认，但开场温吞，前 5 秒没有压力。
  2. **收益入口**：换帖当日她当众说"再缓一缓"。第一格是她打断他的一瞬，问题："她为什么不要这门亲事？"整集收益：反制爽点，但观众不知道她凭什么敢。
  3. **冷开入口（选定）**：临终床前，男人画外说"我心里，一直只有温蘅"，她的脸不能动。第一格是闭着眼的脸与烛火，问题："她是不是要死了？说话的人是谁？"整集收益：死亡真相 + 重生确认 + 反制 + 新目标，四件事一集给完。
- **为什么不更早/更晚开始**：更早会变成宅院日常；更晚会丢掉"她凭什么敢退婚"的因果。
- **开场可见证据**：闭不上的嘴、松开的指节、窗外正开的梨花——观众从这三样反推"她正在死"。
- **观众现在必须知道**：她死过一次、她记得那句话、今天是换帖日。
- **观众暂时不需要知道**：裴珩是谁、玉扣是什么、温蘅长什么样。

## 8. 成功条件与待确认项

- **本轮产物必须保住的创作者选择**：冷开、克制的语气、梨花作为贯穿物、H3 的 4 秒下限带来的长镜头节奏。
- **可以由后续单集继续发现的空白**：裴珩的性格与说话方式、温蘅的动机。
- **若不确认会改变故事方向的问题**：
  - 原著第 4–12 章的实际情节未读，EP002–EP004 的分集只写到方向，需与原文核对后再定。
- **不会阻止继续工作的次要未知项**：裴珩的演员形象、猎场场景板、寺庙内景是否需要。
