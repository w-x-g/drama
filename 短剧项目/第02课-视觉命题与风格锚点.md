# 第 02 课：视觉命题、机位、构图、光线与色彩

> 对应《AI视频制作学习计划.md》4.3.2–4.3.6
> 项目：《梨花误》
> 本课交付物：全剧视觉命题 + 四集视觉命题 + 视觉总谱 + 风格锚点 + 色彩弧线
> 阅读用时：30–40 分钟

---

## 一、本课只讲一件事

> **视觉不是"好看"，是"命题"。**

机位、构图、运镜、光线、色彩，这五样东西不是五个独立的审美选项，而是同一句话的五种翻译。

那句话叫**视觉命题**：用一句话说清"这场戏在视觉上要像什么"。

判断标准：**如果一个视觉选择不能从命题推导出来，它就是装饰。**

---

## 二、视觉命题：一句话定全片

教材里的例子：

> 不是"两个人在吵架"，而是"两个人在越来越窄的空间里，互相把对方逼到墙角"。

前者是剧情，后者是视觉。后者能直接推导出景别、构图、机位、光线。

### 2.1 全剧视觉命题

> **一个被"将就"困在框里的女人，打碎框，走到光里。**

三个关键词，推导出整部剧的视觉系统：

| 关键词 | 视觉推导 |
|--------|----------|
| 困在框里 | 框中框、门框、窗棂、铜镜；人物贴边；对称构图；冷灰 |
| 打碎框 | 越轴、破框、从固定到运动；对称被打破；人物第一次站到画面中心 |
| 走到光里 | 冷灰 → 暖烛；室内 → 门口/窗外；结尾用开放构图和拉远 |

这句话同时决定了**色彩弧线**（冷到暖）和**构图弧线**（框中框到开放）。后面所有选择，都从这里来。

### 2.2 四集视觉命题

| 集 | 视觉命题 | 视觉推导 |
|----|----------|----------|
| EP01 死局重启 | 一个死过一次的人，坐在同一面铜镜前，把所有人都重新看了一遍。 | 铜镜=框中框；她从镜中看人，观众从镜中看她；晨光冷白；机位多从侧面/镜后 |
| EP02 长明灯 | 她走进一座香烟缭绕的庙，把一盏为别人点的灯，举到所有人面前。 | 灯架=引导线+中心构图；香烟=柔光/遮蔽；人群=包围；裴珩的墨色=她身后的锚 |
| EP03 一块玉 | 一块玉在桌上翻了个面，所有温柔都露出了背面。 | 桌面=舞台；俯拍中心构图；玉的特写承担反转；对称构图从中间裂开 |
| EP04 不种梨花 | 她走出那扇门，院子里的梨花被连根拔起，种上了梅。 | 门=最后一次框中框；门外=开放构图；暖烛+梅红；结尾拉远看双影 |

**注意**：四集命题不是剧情简介，每一句都必须能直接推导出画面。写不出推导，就重写命题。

## 三、机位与角度：谁在权力上位

| 角度 | 心理含义 | 本剧用法 |
|------|----------|----------|
| 平视 | 平等、客观 | 沈岁宁重生后看所有人；EP04 裴珩告白 |
| 仰视 | 强大、压迫、英雄感 | EP01 临终，从她躺着的视角仰拍江砚白 |
| 俯视 | 弱小、被审视、命运感 | EP01 俯拍将死的她；EP03 俯拍语塞的江砚白 |
| 正面 | 坦率、对抗 | 江砚白的温润假象；温蘅的柔弱 |
| 侧面 | 观察、距离 | 沈岁宁审视江砚白；裴珩的沉默 |
| 背面 | 神秘、跟随 | 裴珩首次登场；她走出江家 |
| 过肩 | 关系、对话 | 佛寺对峙、厅堂对话 |
| 主观 | 代入 | 她从铜镜里看自己；佛寺里看灯 |
| 荷兰角 | 失衡、不安 | EP03 玉佩揭穿时只用一次 |

### 三个关键机位设计

**1. EP01 临终：仰拍江砚白，俯拍沈岁宁**

她躺着，他坐在床边。镜头从她的视角仰拍他——这是她一辈子的视角：仰视、依附、把将就当成恩赐。切到她时用俯拍——将死、无力、被命运按住。

同一场戏，两个高度，就是两个人的权力关系。

**2. EP02 佛寺：江砚白从平视到俯视**

他刚进殿时，镜头平视甚至略仰，他还是那个温润自信的江公子。裴珩站到她身侧之后，镜头切俯拍——不是他变矮了，是观众的位置变了。

**机位不动，权力变了，所以机位必须动。**

**3. EP04 门口：裴珩跪地，但不仰拍他**

他单膝落地，如果从她的视角俯拍，会拍成"臣服"。这场戏要的是平等，所以镜头保持平视，让两个人处在同一高度。

**低机位不一定代表压迫，也可能是珍视。机位是关系，不是公式。**

## 四、构图：关系与处境

| 构图手法 | 表达 | 本剧用法 |
|----------|------|----------|
| 三分法 | 自然、呼吸感 | 日常对话、行走 |
| 中心构图 | 仪式感、压迫感 | 佛寺灯架、江家厅堂 |
| 对称 | 秩序、礼教 | EP01–03 的宅院；EP04 打破 |
| 负空间 | 孤独、渺小、等待 | 空屋、长桌、佛寺大殿 |
| 框中框 | 被困、窥视、隔离 | 铜镜、门框、窗棂、灯架 |
| 引导线 | 把视线引向主体 | 灯架、走廊、长桌 |
| 前景遮挡 | 层次、窥视感 | 梨花枝、门帘、香炉烟 |
| 视觉重量 | 平衡与失衡 | 她小环境大；她与裴珩并肩；玉在桌面正中 |

### 竖屏构图的四条规则

1. 竖屏的框中框是**纵向**的：门框、窗棂、灯架、屏风，不要用横向画框；
2. 双人关系用**前后站位**，不用左右并排；
3. 权力关系用**上下**表达：站与坐、高与低、门内与门外；
4. 大远景靠**纵深**成立：长廊尽头、天井俯拍、门洞套门洞。

### 四个关键构图设计

**1. EP01 铜镜：三重观看**

铜镜是框中框。她在镜中看自己，观众在镜外看她，镜头又在看她看自己。一个画面，三层观看关系。

重生戏的核心不是"她醒了"，是"她第一次看清自己"。

**2. EP02 灯架：中心 + 引导线**

一排长明灯从近到远，把视线引向"温蘅平安"四个字。她站在灯前，人群在两侧形成包围。

她不是在看一盏灯，她是在所有人的注视下，把一盏灯举起来。

**3. EP03 桌面：俯拍中心，然后裂开**

玉佩放在桌面正中，三个人围着桌子。俯拍中心构图，像审判台。裴珩翻过玉佩的那一刻，构图从对称变成三角，秩序裂开。

**4. EP04 门：最后一次框中框**

她跨出江家的门。这是全剧最后一次用门框构图。门内是框，门外是开放画面。她走出去，构图才真正打开。

## 五、运镜：动机

| 运镜 | 功能 | 本剧用法 | 全剧配额 |
|------|------|----------|----------|
| 推 | 靠近、聚焦、情绪升温 | 佛寺"你为我立过吗"；EP03 验玉 | 15% |
| 拉 | 远离、揭示、抽离 | EP01 结尾；EP04 结尾 | 10% |
| 摇 | 扫视、连接 | 佛寺灯架 | 5% |
| 移 | 横向跟随、展示空间 | 走进佛寺、走廊 | 5% |
| 跟 | 跟随主体、代入 | 马车、她走出江家 | 5% |
| 升降 | 视角变化、命运感 | 俯拍房间、佛寺 | 5% |
| 环绕 | 仪式感、关系张力 | 婚礼、双人（少用） | 0–5% |
| 手持 | 真实、混乱、紧张 | 前世临终一口气 | 1–2 镜 |
| 固定 | 克制、观察 | 全剧主体 | 70% |

### 三条运镜原则

1. **找不到动机，就静止。** 静止也是一种语言。
2. **一镜只做一次运镜。** 推就是推，不要边推边摇。
3. **AI 短剧先求稳。** 固定最稳，缓慢推拉次之，环绕和手持最容易崩。本剧把 70% 的镜头留给固定。

### 三个关键运镜设计

- **EP01 结尾：拉。** 她从桌前抬头，镜头缓慢拉远，窗外梨花入画。拉=抽离，把她一个人留在更大的空间里。
- **EP02 佛寺：推。** 她说"你为我立过吗"，镜头从近景缓慢推到她脸上。推=逼问，观众没有退路。
- **EP04 结尾：拉。** 烛火前，两道影子靠得很近，镜头缓慢拉远。拉=余韵，不打扰。

## 六、光线：真相

| 光线概念 | 作用 | 本剧用法 |
|----------|------|----------|
| 主光 | 决定造型与明暗 | 窗光、佛寺顶光 |
| 辅光 | 控制光比 | 阴天反射光 |
| 轮廓光 | 把人物从背景分离 | 裴珩的墨色衣服配冷轮廓光 |
| 动机光 | 画面里合理存在的光源 | 烛火、长明灯、玉佩反光 |
| 硬光 | 紧张、冷峻 | EP03 揭穿时的侧光 |
| 柔光 | 温和、梦幻 | 温蘅出场、EP04 结尾 |
| 光比大 | 戏剧、悬疑 | EP01 前世 1:8 |
| 光比小 | 平和、日常 | EP04 1:2 |
| 时间感 | 晨/午/昏/夜 | 晨光偏暖、正午硬、黄昏侧逆、夜晚点光 |

### 四集光线设计

| 集 | 主光 | 辅光/轮廓 | 光比 | 时间感 | 情绪 |
|----|------|-----------|------|--------|------|
| EP01 | 阴天窗光 + 烛火 | 冷色环境反射 | 1:4（前世 1:8） | 清晨 | 冷、压抑 |
| EP02 | 佛寺顶光 + 长明灯 | 香烟散射 | 1:6 | 白天 | 对峙、审判 |
| EP03 | 冷白侧光 + 玉反光 | 窗光补暗部 | 1:3 | 午后 | 揭穿、冷静 |
| EP04 | 暖烛 + 晨光 | 暖色反射 | 1:2 | 夜 → 晨 | 暖、释放 |

### 三个关键光线设计

- **EP01 烛光打脸**：全剧唯一的暖源，但暖得廉价。她一辈子守着的那点暖，其实来自一支随时会灭的蜡烛。
- **EP02 长明灯从下往上打**：灯在下方，脸被从下照亮。这不是温暖，是审判——她站在佛前，也站在所有人面前。
- **EP03 玉的反光**：玉佩翻面的一瞬，冷白反光打在温蘅脸上。谎言第一次被光照亮。
- **EP04 烛火暖脸**：全剧第一次允许暖光同时落在两个人脸上。不是灯变暖了，是她终于走到了对的人身边。

## 七、色彩：情绪弧线

### 7.1 色彩语义

| 颜色 | 含义 | 用法 |
|------|------|------|
| 青灰 | 清醒、压抑、旧秩序 | 全片主色 |
| 梨花白 | 将就、前世、死亡 | EP01–03，一次比一次冷 |
| 梅红 | 主动选择、今生 | 只在 EP04 出现 |
| 玉青 | 谎言、真假之辨 | EP03 |
| 佛寺金 | 神圣、审判 | EP02 |
| 烛火橙 | 唯一的暖源 | 全片点缀，EP04 放大 |

### 7.2 色彩弧线

| 集 | 主色 | 辅色 | 点缀 | 饱和度 | 情绪 |
|----|------|------|------|--------|------|
| EP01 | 青灰 `#6F7C7A` | 梨花白 `#E8E6DF` | 烛火橙 `#C98A4B` | 20–30% | 冷、压抑 |
| EP02 | 冷青 `#4F6468` | 佛寺金 `#B08A4F` | 香烟灰 `#8A8578` | 25–35% | 对峙、审判 |
| EP03 | 冷白 `#D9DEDC` | 玉青 `#A8C0B8` | 墨 `#2E3330` | 15–25% | 揭穿、冷静 |
| EP04 | 暖烛 `#D9A05B` | 梅红 `#8E3B46` | 暖白 `#F0E4D2` | 35–45% | 暖、释放 |

**注意**：EP04 不是高饱和，只是全片唯一允许暖色占主导。整部剧仍然是低饱和。

### 7.3 人物色彩

| 人物 | 主色 | 弧线 |
|------|------|------|
| 沈岁宁 | 月白、青灰 | 前期冷灰；EP04 加梅红点缀 |
| 江砚白 | 月白、竹青 | 前期温润；后期逐渐褪成灰白 |
| 裴珩 | 玄色、墨黑 | 全剧唯一的深色锚点，始终不变 |
| 温蘅 | 藕荷、浅粉 | 前期柔弱；后期冷白 |

**规则**：色彩跟着人物关系走，不跟着场景好看走。

## 九、风格锚点

### 9.1 参考片（给人看的）

| 参考 | 取什么 |
|------|--------|
| 《知否知否应是绿肥红瘦》 | 宅院空间、自然光、礼法日常 |
| 《甄嬛传》 | 框中框、权力站位、低饱和 |
| 《花样年华》 | 框中框、压抑感、克制的红色点缀 |

参考片不是拿来抄镜头，是拿来对齐"质感方向"。

### 9.2 视觉参数（给 AI 看的）

| 项目 | 设定 |
|------|------|
| 画幅 | 竖屏 9:16 |
| 焦段 | 35mm 为主，50mm 用于特写 |
| 景深 | 浅 |
| 色调 | 低饱和青灰 + 梨花白 |
| 光线 | 阴天柔光 + 烛火/灯笼实用光 |
| 质感 | 细颗粒、低对比、轻微褪色 |
| 运镜 | 固定为主，缓慢推拉为辅 |
| 表演 | 克制，不哭喊，不瞪眼 |

### 9.3 风格 Prompt（可直接复用）

```text
Chinese period drama, Song dynasty, low saturation teal-grey palette,
pear-blossom white, soft overcast daylight, candle practical light,
35mm lens, shallow depth of field, fine film grain, low contrast,
muted colors, vertical 9:16 composition, cinematic, restrained performance,
no modern elements
```

### 9.4 禁用清单

- 高饱和红、荧光色、霓虹；
- 现代物件：塑料、金属反光、电线、空调；
- 繁复头饰、影楼妆、塑料皮肤、过度磨皮；
- 卡通感、CGI 感、游戏引擎感；
- 慢动作滥用、炫技环绕、无动机运镜。

## 十、本课小结

1. **视觉命题是原文，机位、构图、运镜、光线、色彩是翻译。** 不能从命题推导的选择，都是装饰。
2. **机位 = 权力**：仰俯之间，谁在上位一目了然。
3. **构图 = 关系**：框中框是困，开放构图是自由，对称是秩序，裂开是反抗。
4. **运镜 = 动机**：找不到动机就静止；AI 短剧 70% 用固定。
5. **光线 = 真相**：动机光让光可信，光比决定戏剧强度。
6. **色彩 = 情绪弧线**：全剧一条线，从青灰到暖烛，从梨花到梅。
