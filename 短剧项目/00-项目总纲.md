# 《梨花误》AI 短剧项目总纲

> 教材小说：《重生后我退了婚约才知道暗恋我十年的人一直在等我》
> 课程来源：《AI视频制作学习计划.md》
> 项目规格：4 集 × 60–90 秒 · 竖屏 9:16 · 冷调宅斗
> 项目代号：梨花误
> 教学方式：分阶段实战，每课一个交付物，验收不过不进入下一课

---

## 一、项目定位

**一句话故事**：被"将就"了一辈子的沈岁宁重生回到定亲当日，退掉婚约，才发现那个暗恋她十年的人一直在等她。

**类型**：古装重生 · 宅斗 · 追妻火葬场 · 双向暗恋

**改编原则**：

- 12 章压成 4 集，每集 3–5 个 beat，集尾必留钩子；
- 保留小说的"冷叙述"气质，不喊口号、不解释内心，靠画面和台词留白；
- 每集只讲一个核心动作：退婚 → 揭灯 → 验玉 → 选择。

---

## 二、四集结构

| 集 | 覆盖章节 | 时长 | 核心事件 | 集尾钩子 | 情绪目标 |
|----|----------|------|----------|----------|----------|
| EP01 死局重启 | 第 1–3 章 | 90s | 临终被"无愧于心"刺死 → 重生十六岁 → 拒婚 → 江砚白因温蘅离开 → 写下"裴珩" | 马蹄声停在府门外 | 冷、清醒、压抑的爽 |
| EP02 长明灯 | 第 4–6 章 | 90s | 裴珩登门答应护送 → 江砚白拦人被抓手腕 → 佛寺当众揭长明灯 → 裴珩挡身 | "若你哪日想好了……"她步子慢下来 | 对峙、渐暖、公开打脸 |
| EP03 一块玉 | 第 7–10 章 | 90s | 装病 → 裴珩送茯苓糕求婚 → 母亲揭"定亲前三日" → 温蘅送玉佩 → 裴珩验出贡品 | "明日，我父亲会登江家的门" | 甜、悬、揭穿 |
| EP04 不种梨花 | 第 11–12 章 | 90s | 耳光 → 裴珩跪地告白"暗恋八年" → 退婚 → 提亲 → 新婚夜"拔梨树种梅" | "还好是你" | 释放、暖、余韵 |

**分集节奏模板**（每集 90s）：

| 时间 | 功能 | 要求 |
|------|------|------|
| 0–10s | 钩子前置 | 第一个画面就要有冲突或异常 |
| 10–55s | 主体推进 | 3–4 个 beat，每个 beat 至少一个镜头 |
| 55–80s | 情绪高点 | 景别推到最近，或给最大反差 |
| 80–90s | 集尾钩子 | 一句台词 / 一个动作 / 一个声音，切黑 |

## 三、视觉基调（风格锚点）

| 项目 | 设定 |
|------|------|
| 画幅 | 竖屏 9:16 |
| 色彩 | 低饱和青灰 + 梨花白 + 烛火暖点 |
| 参考 | 《知否》的宅院质感 + 《甄嬛传》的框中框窥视构图 |
| 镜头包 | 35mm 等效，浅景深，固定机位 + 缓慢推近为主 |
| 光线 | 阴天柔光打底 + 烛火/灯笼实用光，光比 1:4–1:8 |
| 质感 | 细颗粒、低对比、轻微褪色，不做高饱和 |
| 运镜 | 少动。只在情绪转折处推、拉、跟 |
| 禁用 | 高饱和、霓虹、现代物件、繁复头饰、卡通感、塑料皮肤 |

**色彩弧线**（对应 md 4.3.6）：

> EP01 冷灰 + 微弱烛暖（死局） → EP02 冷青 + 佛寺香烟金（对峙） → EP03 冷白 + 玉青（揭穿） → EP04 暖烛 + 梅红（新生）

**视觉母题**：

| 母题 | 含义 | 用法 |
|------|------|------|
| 梨花 | 将就、前世、死亡 | EP01–03 反复出现，一次比一次蔫、一次比一次冷 |
| 梅 | 主动选择、今生 | 只在 EP04 出现，色彩第一次转暖 |
| 铜镜 | 重生、自我审视 | 框中框构图，EP01 核心道具 |
| 长明灯 | 江砚白的偏心、公开审判 | EP02 佛寺戏的视觉中心 |
| 玉佩 | 温蘅的谎言、真假之辨 | EP03 翻面验真，特写承担反转 |

## 七、三条铁律

1. **每课一个交付物**，验收不过不进入下一课；
2. **所有分镜按五律**：时长律、首尾帧律、单动作律、一致性律、可提示律；
3. **每个镜头过三问**：它在讲什么？删掉会怎样？AI 拍不拍得出来？
